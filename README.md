# NotebookLM Chat Exporter

A lightweight, minimal browser extension to export your NotebookLM chat history to a formatted Markdown (`.md`) file.

## Features

Features one-click export of your full chat history. Operates with zero external dependencies using just vanilla JavaScript.

## Installation

### Firefox

**Option 1: Firefox Add-ons (Recommended)**
- Download from [Mozilla Add-ons Store](#) *(Link coming soon)*

**Option 2: Manual (For Developers)**
1. Go to `about:debugging#/runtime/this-firefox`
2. Click "Load Temporary Add-on"
3. Select `manifest.json` from this repository

### Chrome

**Option 1: Chrome Web Store (Recommended)**
- Download from [Chrome Web Store](https://chromewebstore.google.com/detail/notebooklm-chat-exporter/ffkhelaagbcaeidogobojfedgkhfchlg)

**Option 2: Manual (For Developers)**
1. Go to `chrome://extensions/`
2. Enable "Developer mode" (top right)
3. Click "Load unpacked"
4. Select the folder containing this repository
